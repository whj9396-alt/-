# HAOJ1E 多站通用 USDT 直收插件

WooCommerce 直连 USDT 收款插件，支持 `TRON (TRC20)` 和 `Ethereum (ERC20)`。顾客付款直接进入站长自己的对应网络钱包，网站读取已固化链上事件并自动完成订单，不经过 NOWPayments 等支付服务商。

## 两个独立支付渠道

- `HAOJ1E + 当前域名 + USDT-TRC20`
- `HAOJ1E + 当前域名 + USDT-ERC20`

两个渠道分别保存收款地址、汇率、RPC 节点和扫描状态。可以只启用一个，也可以同时启用。TRC20 必须填写 `T` 开头地址，ERC20 必须填写 `0x` 开头 Ethereum 地址。

## 安全边界

- 插件只保存公开收款地址，绝不需要助记词、私钥或钱包密码。
- TRC20 只接受 Tether 官方 TRON 合约 `TR7NHqjeKQxGTCi8q8ZY4pL8otSzgjLj6t`。
- ERC20 只接受 Tether 官方 Ethereum 合约 `0xdAC17F958D2ee523a2206206994597C13D831ec7`。
- 必须同时匹配网络、官方合约、收款地址、精确六位小数金额、成功回执和已固化区块。
- 同一链上事件使用数据库事务原子抢占，避免重复发货。
- 页面按钮、付款截图和顾客自报交易哈希都不能触发发货。
- 可给每个网络配置第二个独立 RPC 节点，进行双节点交叉验证。

## 金额和最低额度

插件不设置最低订单金额。任何大于零且能换算为 USDT 六位小数精度的订单都可以创建付款页面，最低技术精度为 `0.000001 USDT`。

为了在同一个公开地址上识别不同订单，插件会在基础金额后加入不会重复的微小尾数，例如基础金额 `0.600000`，最终显示 `0.603217 USDT`。顾客必须完整支付页面显示的六位小数。

钱包或交易所的最低提币额、固定提币费和链上 Gas/能量费属于外部限制，插件无法取消。ERC20 网络费通常高于 TRC20，小额订单建议优先展示 TRC20。

## 安装

1. 上传并启用 `HAOJ1E-multisite-direct-usdt-v1.2.0.zip`。
2. 打开 `WooCommerce -> 设置 -> 付款`。
3. 分别进入 TRC20 或 ERC20 渠道，填写对应网络的公开收款地址。
4. 填写 `1 USDT 等于多少本站币种`；USD/USDT 商店通常填 `1`。
5. 保存并确认节点检测通过，再启用渠道。
6. 打开 `WooCommerce -> 链上收款监测`，确认对应网络持续扫描成功。

默认测试节点为 `https://api.trongrid.io/jsonrpc` 和 `https://ethereum-rpc.publicnode.com`。正式运营建议为每条启用的网络配置稳定的独立 RPC 服务。

## 多站使用

- 同一个 ZIP 可安装到多个 WooCommerce 网站，插件名称会自动跟随当前域名。
- 每个独立网站、每条网络建议使用不同公开收款地址，避免订单归属混淆。
- 原来的 TRC20 设置和订单保持兼容；升级后按需配置新的 ERC20 渠道。
- 每个站点使用自己的数据库表和订单尾数，不共享订单数据。

## 自动确认流程

1. 顾客选择 TRC20 或 ERC20 并创建订单。
2. 页面显示对应网络、精确金额、地址和二维码。
3. 插件每分钟扫描对应主网，付款页也会触发安全状态刷新。
4. 链上验证全部通过后调用 WooCommerce `payment_complete()`。
5. WooCommerce 继续处理库存、订单邮件和虚拟商品交付。

超时到账、少付、错网络、合约不符或付款期间订单被改价都会进入拒绝或人工复核，不会自动发货。

## 环境要求

- WordPress 6.5+、WooCommerce 8.0+、PHP 7.4+（建议 PHP 8.2）
- HTTPS、InnoDB、每分钟运行的 WordPress Cron 或服务器 Cron

## WP-CLI

```bash
wp psdu health
wp psdu scan
```

停用或删除插件不会主动删除审计记录。数据库表为 `{prefix}psdu_quotes` 和 `{prefix}psdu_events`。
